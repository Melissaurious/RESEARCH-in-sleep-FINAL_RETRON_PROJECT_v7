## 4. Plots still to build

None of these blocks the chapter. Each is specified enough to drop straight into the notebook;
the data already exists except where noted.

### B1 — Outgroup separation *(highest value; a claim in the chapter rests on it)*
**Why.** `OutgroupA` contributes 3,319 of the 16,458 distinct RNA sequences and `OutgroupB` 338 —
together 22 % of the sequence set, but only 3.7 % of calls. The chapter now states this; a panel
should show it.
**Shows.** Per model, two bars — share of calls and share of distinct sequences — with the two
outgroup models coloured apart. The point is that the ranking inverts between the two axes.
**Data.** `tables/C3_model_composition.tsv`, columns `pct_of_calls` and `pct_of_exact_seq`. Nothing
to compute.
**Where.** `build_nb_part4.py`, beside C3 → plot cell **53**.

### B2 — MULTI score margins
**Why.** The chapter claims median 5 bits against 81.7 bits in a seeded control. There is **no
workbench table and no figure** behind it; it is quoted from the landed `g4` bundle.
**Shows.** Two overlaid margin distributions (MULTI vs seeded control), with the 20-bit line marked
and the 99.8 % below it annotated.
**Data.** `multi_hmm_evidence_v1.parquet` (`margin_bits`, 7,593 rows) and
`results/dbchar_g4_family_baseline/tables/g4_multi_hmm_margin_comparison.tsv`.
**Where.** section **G scaffold, cell 92** — currently empty.

### B3 — RT length ECDF
**Why.** The shape figure to use instead of a violin. `g7b/fig08_rt_length_ecdf` is the precedent.
**Shows.** ECDF of length for the top ~8 families, complete calls only, one line each. Exact, no
bandwidth, and it overlays many families legibly where a violin cannot.
**Data.** needs one new query over `rt_exact_v1` / `rt_family_baseline_v1` — cheap.
**Where.** `build_nb_part3.py`, beside B2 → plot cell **36**.

### B4 — Geometry schematic *(drawn, not measured)*
**Why.** Readers cannot parse the `signed_distance_bp` sign convention from prose, and the
upstream / downstream / overlapping trichotomy is a definition, not a result.
**Shows.** One RT gene, one RNA in each of the four positions, with the sign and the gap
annotated; plus what "no intervening CDS" means.
**Data.** none — hand-drawn SVG, same treatment as `retron_ncrna4.svg`.
**Where.** section M, before M2 → cell **116**.

### B5 — Locus gallery
**Why.** `fig:operons` shows only the clean case. Proposal F5 asks for the atypical ones.
**Shows.** Six panels, one each: adjacent, overlapping, near-range downstream, distant,
opposite-strand, non-Retron.
**Data.** none new — the M2 machinery needs only a different selector per panel.
**Where.** `build_nb_part8.py`, after M3 → cell **123**.

### B6 — Cross-labelled and cross-family detail
**Why.** `tab:crosslabel` is currently one row. The 12 proteins deserve their lengths and label
evidence shown once.
**Data.** `tables/L2_cross_label_proteins.tsv` — already computed.
**Where.** section G, cell **92**, beside B2.

## 5. Playing with any of these

Cells are strictly paired: an **odd cell caches the table**, the **next plots it**. To restyle,
edit only the plot cell — it reads the cached TSV and is instant. Cell indices are for the
152-cell build of 2026-09-17 and shift as soon as you add cells, so navigate by the heading.
